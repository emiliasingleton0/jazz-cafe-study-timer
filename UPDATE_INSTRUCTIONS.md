# Jazz Café v2 Update Files

This update adds:

- Welcome-back text saved with LocalStorage
- Passport progress chips for visited cities
- Focus-session stats saved locally
- Café ambience toggle using browser audio
- Timer pause/reset/back controls that pause or stop music properly
- City-specific record crate dialogue
- Closing-time scene when the session ends
- Improved record-player animation styling

## How to update your GitHub project with GitHub Desktop

1. Download and unzip this folder.
2. Open your cloned `jazz-cafe-study-timer` folder on your computer.
3. Copy these updated files/folders into your project folder:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/`
   - `UPDATE_INSTRUCTIONS.md` optional
4. Choose **Replace** if your computer asks.
5. Open GitHub Desktop.
6. You should see changed files listed automatically.
7. Commit with a message like:

   `v2 update - added passport progress, ambience, and café polish`

8. Click **Push origin**.
9. Wait about 1–3 minutes for GitHub Pages to update.
